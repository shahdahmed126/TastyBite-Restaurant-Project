TastyBite Restaurant Project

Overview

A restaurant web application built with Python and Django, designed to manage menu items, customer checkout, and table reservations.

Features

- Add, edit, and delete restaurant menu items.
- Customer checkout form with validation.
- Table reservation form with validation.
- Upload and display menu item images.
- Staff menu management.
- Django Admin integration.

Technologies

- Python
- Django
- SQLite
- HTML and CSS

Project Structure

- "restaurant/" — Models, forms, views, URLs, and templates.
- "restaurant_proj/" — Django project configuration.
- "manage.py" — Django management utility.
- "requirements.txt" — Project dependencies.

How to Run

Install dependencies:

pip install -r requirements.txt

Apply migrations:

python manage.py migrate

Start the development server:

python manage.py runserver

Open "http://127.0.0.1:8000/" in your browser.

Note

This project was developed as part of a learning experience with Django.
